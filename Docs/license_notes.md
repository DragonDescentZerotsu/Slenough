# License Notes

Phase 2 code in this repository is an original baseline implementation.

No code, model weights, or data files were copied from external sleep-classifier projects.

Current classifier status:

- The app uses an original, simple motion-first rules engine.
- No `ojwalch/sleep_classifiers`, `sleep_accel`, or `OxWearables/asleep` code has been integrated.
- Future model work should keep licenses and commercial-use restrictions explicit before copying code or weights.

Open-source projects mentioned in planning notes can be used for research context only:

- `ojwalch/sleep_accel`: useful reference for Apple Watch acceleration and heart-rate collection patterns. Check and preserve MIT license text before copying any code.
- `ojwalch/sleep_classifiers`: useful reference for feature design and classifier direction. Check and preserve MIT license text before copying any code or model artifact.
- `OxWearables/asleep`: algorithm inspiration only unless a compatible commercial license is obtained.
- GPL projects such as `pyActigraphy`: do not copy code into this app.
